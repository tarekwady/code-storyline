# Changelog

## 0.1.1

- Simpler panel: just the file name, the story, and two buttons, `history` and the model. Regenerate Storyline moved to the panel's **…** menu.
- No zoom buttons or legend on screen anymore. Zoom with ctrl + scroll, a pinch, or `+` `-` `0`.
- Clearer README, with a link to this page.

## 0.1.0

- First release. Show Code Storyline explains a code file step by step, in plain words, with the exact code on every card.
- Click a part to ask follow-up questions, simpler or deeper.
- Storylines are saved per file, with history and your questions.
- Your Anthropic API key is kept in VS Code's encrypted storage.
